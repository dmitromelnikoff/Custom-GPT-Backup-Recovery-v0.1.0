# Диагностика

| Симптом | Возможная причина | Безопасная реакция |
|---|---|---|
| `FILE_NOT_SHOWN_IN_EDITOR` | Открыта вкладка «Создать» вместо «Конфигурация» | Проверить переключатель и раздел «Знания» |
| `EDITOR_UI_ACTION_ERROR_TimeoutError` | Нестабильный selector/scroll или изменился UI | Диагностика рядом с точной кнопкой файла; не кликать наугад |
| `PREVIEW_DOWNLOAD_ACTION_NOT_VISIBLE` | Команда в просмотрщике/iframe/другом окне либо реально недоступна | Сохранить `Direct_GPT_UI_probes/..._preview.json`, отложить |
| `TargetClosedError` | Просмотрщик закрыл страницу/открыл новую | v11 учитывает новые/закрытые окна; повторный запуск только после проверки |
| `HTTP 404` | Нет конкретного содержимого/неверная ссылка | Подтвердить вручную, не приписывать все ошибки UI статусу 404 |
| `HTTP 415` | Неподходящий файловый endpoint | Не подбирать обходные методы; видимый редактор или локальный архив |
| `HTTP 401/403/429` | Требуется вход, отказ в доступе или ограничение | **ОСТАНОВИТЬ** загрузки. Не обходить ограничения. Дождаться нормального доступа |
| `NOT_FOUND_UNCONFIRMED` в Library | Не доказано, что поиск действительно был пустым | Не удалять запись, не считать файл потерянным |
| Файл есть, но `size_only` | Копия из Library/Obsidian/другого GPT | Сохранить статус кандидата и происхождение |
| Одинаковые имена в нескольких GPT | Разные `file_id`, возможны версии | Нельзя назначать по имени; проверять SHA и уникальные источники |
| Внутри GPT два одинаковых имени | Разные Knowledge-записи, ordinal | Сохранять отдельный путь `01_...`, `02_...` и связку file ID |
| `--attach` не находит Chrome | Chrome запущен без CDP или с другим профилем | Проверить выделенный локальный CDP-профиль, не открыть порт наружу |

### Что отправить разработчику при ошибке

Можно отправить **обезличенные** статус-коды и метаданные UI, не отправляя токены, cookie, browser profile, полные Instructions или настоящие файлы Knowledge. Прежде чем выкладывать даже диагностический JSON, проверьте наличие приватных имён и путей.
