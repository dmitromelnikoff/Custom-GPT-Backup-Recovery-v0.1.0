# Проверка качества

## Что подтверждено пользователем

- Реальные загрузки через редактор GPT (v5, v9, v10, v11), массовые серии **1 306** и **339** файлов.
- Безопасная остановка при HTTP 403.
- Автоматический перенос отсутствующих файлов из Obsidian (34 + 41) и установка доноров.
- Автоматический импорт MD/изображений из локальных папок.
- Скачивание всех профильных иконок (сообщение пользователя).

## Что проверено в этом репозитории

- Python-скрипты компилируются без синтаксических ошибок.
- Новый `tools/archive_cli.py` проверяется на **синтетических** snapshot и byte files, включая отсутствие перезаписи и конфликты SHA.
- `.gitignore` и сканирование пакета не допускают случайной поставки приватных backup-файлов.

## Что не проверено в этом окружении

- Реальный доступ к аккаунту пользователя через CDP.
- Стабильность текущего на дату запуска UI ChatGPT (текст и роли компонентов могут измениться).
- Работоспособность `experimental/bootstrap_snapshot_legacy.py` в будущем: использует недокументированные endpoint'ы.
- Побайтовая идентичность локальных кандидатных файлов их экземплярам на стороне ChatGPT.

## Команды

```powershell
python -m unittest discover -s tests -v
python -m compileall -q scripts tools experimental
python tools/archive_cli.py audit
```
