# Какие методы оставить, какие исключить

## Проверено реальными прогонами — основа проекта

| Метод | Итог | Статус |
|---|---|---|
| Авторизованный Chrome/CDP + Playwright + видимый GPT Builder | Успешно скачивал Knowledge поочерёдно и массово | **PRIMARY** |
| Сначала нажать «Конфигурация» (`radio`), затем «Знания» | Устранило отсутствие имён файлов | **PRIMARY** |
| Точная кнопка с именем Knowledge, просмотрщик/iframe, событие download | Работало в v5+ | **PRIMARY** |
| Сверка размера, SHA-256 и журнал receipt | Защитила от части ошибок и фиксировала происхождение | **PRIMARY** |
| Паузы 15–30 сек., отложенные ошибки, повторный запуск | Работало при длинном обходе | **PRIMARY** |
| Остановка при 401/403/429 вместо повторов и обхода блокировки | Сработала при 403 и 429 | **SAFETY** |
| Поиск локальных исходников в Obsidian (только чтение) | 34 + 41 + дополнительные восстановленные копии | **FALLBACK** |
| Общие базы, SHA и отдельное происхождение | Помогли восстановить семейства GPT без смешения file ID | **FALLBACK** |
| Скачивание профильных аватаров отдельной утилитой | Владелец подтвердил успех | **SEPARATE** |

## Экспериментальные / не рекомендуется как основной канал

| Метод | Наблюдавшийся отказ | Решение |
|---|---|---|
| Прямое скачивание через недокументированный `backend-api/estuary/content` / signed URL | HTTP 404, 415, устаревшие ссылки | **НЕ основной способ** |
| Library по имени файла | Возможна другая версия с тем же именем и даже близким размером | Только `LIBRARY_CANDIDATE`, не оригинал |
| Массовый Library UI-поиск | 15 `NOT_FOUND_UNCONFIRMED`, затем 429 | Диагностировать отдельно; не повторять массово |
| Ранний GPT UI без переключения «Создать» → «Конфигурация» | `FILE_NOT_SHOWN_IN_EDITOR` | Заменён v2+ |
| Поиск по тексту + клики/скроллы вокруг файла | Многократный скролл и TimeoutError | Заменён точной кнопкой |
| Только кнопка «Скачать» на основной странице | `PREVIEW_DOWNLOAD_ACTION_NOT_VISIBLE` | Проверять просмотрщик/iframe |
| Остановка всей очереди после первой UI-ошибки | Блокировала остальные GPT | Отложенные ошибки и переход к следующему |
| `--shared-priority` без учёта ранее проблемных GPT | Зацикливал операционный прогресс на ранее проблемном семействе GPT | Ставить подтверждённые источники вперёд, проблемные назад |
| Небольшие прогоны по 2–5 GPT | Работали для диагностики, но слишком медленно для 250 GPT | Для массового обхода `--unattended` |
| Считать совпадение имени + размера идентичностью оригинала | Ошибочный уровень достоверности | Кандидат + происхождение + SHA + явные ограничения |
| Официальный экспорт бесед как замена списку собственных GPT | Содержит ссылки на GPT, не доказывает владение и полную конфигурацию | Не считать надёжным snapshot |

## Версии скрипта прямого скачивания

- **v1–v4:** прототипы и диагностика, нет оснований использовать для нового проекта.
- **v5:** первый подтверждённый рабочий файл.
- **v6–v8:** очередь, отложенные ошибки, доноры.
- **v9:** устойчивый просмотрщик, реальные серии 6/6 и 11/11.
- **v10:** фильтр проблемных GPT; реальный прогон 7/8.
- **v11:** рекомендованная основная версия; два длинных реальных запуска **+1 306** и **+339**.

Не добавляйте в GitHub одиннадцать устаревших рабочих копий без необходимости: актуальный код v11 и этот журнал решений достаточны для повторения.
